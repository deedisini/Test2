# Car Gallery

A responsive car gallery built with **React** as a front-end web development project. The project showcases a collection of cars through reusable components and interactive UI elements.

## Overview

**Car Gallery** is a front-end project created to practice the fundamentals of React and component-based web development.

The project focuses on building reusable UI components, passing information between components with props, managing state, and creating interactive elements through conditional rendering.

## Features

* Car gallery displaying vehicle information
* Reusable `CarCard` components
* Component-based UI structure
* Data passing through React props
* State management for interactive elements
* Login modal with conditional rendering
* Show/hide password functionality
* Responsive interface

## Technologies Used

* **React**
* **JavaScript**
* **HTML5**
* **CSS3**
* **Vite**
